# Quiz POO & UML

Quiz moderno de **Programação Orientada a Objetos** e **UML** com 5 provas e 100 questões.

## Características

- 5 provas com 20 questões cada (100 no total)
- Questões de múltipla escolha sobre POO e UML
- Design moderno, responsivo e com animações
- Salvamento automático com `localStorage` (sem login)
- Sistema de titulações divertido baseado na nota
- Pronto para GitHub Pages

## Como usar

1. Abra o site
2. Escolha uma prova
3. Responda as 20 questões
4. Veja sua nota e titulação
5. O progresso fica salvo no navegador

## Ativar GitHub Pages

1. Vá em **Settings** do repositório
2. No menu lateral, clique em **Pages**
3. Em **Source**, selecione **Deploy from a branch**
4. Branch: `main` / pasta: `/ (root)`
5. Salve

Depois de alguns minutos o site estará disponível em:

**https://mottagustavo.github.io/quiz-poo-uml/**

## Tecnologias

- HTML + CSS + JavaScript puro
- Um único arquivo `index.html`
- Sem backend, sem banco de dados, sem login
